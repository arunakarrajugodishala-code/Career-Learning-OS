# v5.0.6 — Assessment quality and practice

Added a separate targeted-practice centre using the existing v3.1 applied curriculum question bank. Includes subject selection, random question/option order, question count, explanations, bounded local attempt history, and downloadable evidence audit. It does not modify v3.2 assessment results.

## Limitations
- No newly independently verified questions; practice draws from existing questions, so repeat attempts can memorise answers.
- Not a certification, not a complete syllabus assessment, and not independent practical evaluation.
- Browser interaction, accessibility, real-device, offline and backup restoration tests remain pending.
- Production release remains BLOCKED.
