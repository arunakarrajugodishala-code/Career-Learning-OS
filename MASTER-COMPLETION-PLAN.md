# Career Learning OS — Master completion plan

Current baseline: v3.4 development candidate. No automatic claim of certification, 100% curriculum coverage or guaranteed employment.

## Ordered releases and exit gates

1. v3.4: project assessment and evidence tracking (implemented, needs browser/device verification).
2. v3.5: curriculum inventory for 15 pathways, explicit topic-by-topic learning objectives, coverage gaps and prerequisites.
3. v3.6–v3.8: complete foundation, healthcare and advanced courses with examples, guided labs and synthetic practice data.
4. v3.9: assessment banks with answer reviews, blueprint coverage, repeated-attempt safeguards and practical grading rubrics.
5. v4.0: verify every external resource and timestamp checks; record content expert sign-off.
6. v4.1: consolidate navigation and accessibility, keyboard, screen reader, 320px/mobile and laptop browser tests.
7. v4.2: test install/offline/update, backup/restore/undo and migration; privacy and security review.
8. v4.3: career portfolio, CV/interview materials, and up-to-date sponsorship guidance with authoritative citations.
9. v4.4: optional secure cross-device sync only if a vetted backend and consent are provided; otherwise export/import is the supported method.
10. v5.0: final release only after every mandatory gate has reproducible PASS evidence.

## Mandatory evidence

- All scripts parse, every referenced asset exists, navigation routes resolve.
- Automated real browser tests click every navigation entry and key form action; check console errors, keyboard access, mobile overflow.
- Full backup round-trip on two browsers and devices; offline update and reinstall test.
- Complete curriculum mapping and substantial content for each promised proficiency level.
- Question bank reviewed for accuracy, ambiguity, fairness and breadth; real practical project reviewed independently.
- External resources verified and dated; current career/immigration rules checked against official sources.
- Accessibility, security, privacy, copyright and data retention reviewed.
- Unrun or blocked tests marked NOT_TESTED, never PASS.

## Release rule

If any mandatory gate is FAIL, REVIEW or NOT_TESTED, status is RELEASE BLOCKED. Never promise zero mistakes.
