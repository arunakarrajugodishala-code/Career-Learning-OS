# Production acceptance gates (all mandatory)

1. **Syllabus:** a maintained matrix maps each of 15 career roles to beginner/intermediate/advanced competencies and prerequisites. No empty modules or cycles.
2. **Content:** each required lesson includes objectives, explanations, examples, guided and independent practice, mistakes, revision, and accessible alternatives; qualified reviewers sign off accuracy.
3. **Resources:** every individual video/resource URL is opened, mapped to its objective, checked for accessibility/licence and assigned a review date.
4. **Assessments:** answer keys independently verified; sufficient varied questions, randomised retests, scoring, and practical rubrics; self-reports never labelled certified mastery.
5. **Career:** role-specific CV, interview, project portfolios, evidence checklist and employer-specific official immigration/sponsorship checks with timestamps.
6. **Progress:** export/import on two independent browsers, malformed and oversized backups, schema migration and recovery; no loss of existing data.
7. **UI:** every nav view, action, button, select, input and form exercised on desktop and narrow mobile; no horizontal overflow, focus traps or inaccessible labels.
8. **Offline:** install PWA, disconnect, navigate cached lessons, restart and update; confirm new and existing progress persist.
9. **Security/privacy:** verify no real patient data, no secrets in public repository, output escaping, dependency and content-security review, safe handling of user-entered content.
10. **Release:** no critical/high issues, evidence links for each test, external reviewer sign-off and rollback plan. An unrun test is NOT_TESTED.

Optional enhancements (not substitutes for gates): secure opt-in account sync, searchable global syllabus, diagnostic placement test, technical-English practice, downloadable certificates of participation clearly marked non-accredited, calendar reminders, and a source freshness monitor.
