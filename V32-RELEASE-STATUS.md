# v3.2 Assessment Engine — release status

## Built
- 8 applied units, 5 knowledge questions per unit (40 total).
- Randomised question and choice order for each attempt.
- 80% threshold (4 of 5), explanations, local attempt history (last 20), review reminder after 1 or 7 days.
- Independent project evidence notes (self-reported; never certified).
- Previous v3.1 and earlier learning sections retained.

## Important limits
- Five questions per unit are formative, not enough to prove advanced mastery.
- Questions are not independently peer-reviewed; retakes use the same bank.
- No independent grading, cross-device automatic sync, real-device browser verification or accessibility audit.
- Local browser storage can be lost; export backups.
- Production acceptance remains BLOCKED.
